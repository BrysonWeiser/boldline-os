**Why they exist:** `createCampaign` on Meta hard-fails without an image, and the Meta App Review path (KB `meta-marketing-api`) needs real ads actually delivering on the house account for 15+ days. Bryson asked for images he could upload rather than sourcing stock.

**HARD RULE followed throughout — no invented proof.** BoldLine has zero clients as of 2026-08-12, so every line is a claim about *what the service is or how it works*, never about results it has produced. No "we generated X leads", no star ratings, no testimonials, no client logos, no fabricated case-study numbers. That would be both false and the kind of thing Meta rejects. Also **no emojis** — these are the most client-facing surface there is (standing rule, KB `client-email-center`).

**The seven angles:**
| id | Headline | Angle |
|---|---|---|
| `top-of-google` | "Your competitors are **buying the top of Google**." | Competitive loss aversion — the strongest cold opener |
| `phone-ringing` | "Ads that make **the phone ring**." | Outcome in the prospect's own language |
| `not-a-website` | "A website tells them you exist. **A landing page makes them call**." | Sells the landing-page half, which is the differentiator |
| `you-run-the-jobs` | "You run the jobs. **We run the ads**." | Done-for-you / time back |
| `own-your-account` | "You own your **ad account**. Always." | The hard business constraint turned into a selling point — most agencies hold the account hostage |
| `niche-roofing` | "**Roofers:** stop buying shared leads." | Named-niche; shared-lead resentment is the sharpest pain in roofing |
| `niche-hvac` | "**HVAC:** own the searches that matter." | Named-niche; intent framing |

Niche-first beats generic — swap the niche word and rebuild for each vertical Lead Scout is targeting. All CTAs point at a 30-minute call (the Calendly funnel, KB `my-ads-internal-account`) except `not-a-website` ("See what we build").

**Sizes rendered:** 1080x1080 (feed square — the workhorse), 1080x1350 (portrait, most feed real estate), 1080x1920 (Stories/Reels, top and bottom padded for the platform's UI chrome), 1200x628 (link/landscape, also fine for Google Display). Stories are only rendered for the three strongest angles. Per-placement type `SCALE` map — landscape needed 0.8 (0.62 left dead space; the whole point of the knob).

**Design:** brand ink `#070810`, gold from `C.gold`, a gold bloom off the top-right corner + a violet counter-bloom bottom-left, a masked hairline grid for texture, a gold rule across the top, logo + brand lockup + gold kicker, one accent line in the headline, gradient CTA pill and the bare domain. No stock photography anywhere — typographic, which reproduces cleanly at every size and can't look like everyone else's stock library.

**Regenerate:** `node scripts/build-ad-creatives.js [outDir]` (needs `playwright` installed; not a runtime dep). It **fails the run if any creative overflows its canvas**, so a headline edit can't silently ship clipped. Edit the `CREATIVES` array to change copy or add a niche.
